What this experiment shows

  1. Login issues both an access token (short) and a refresh token (long).
  2. API calls use only the access token. When it expires you get 401.
  3. Call Refresh to get a new access token (old refresh is rotated).
  4. Sensitive values (API keys, OAuth secrets) are encrypted with AES-256-CBC before storage.
  5. Plaintext is never stored — only ciphertext + IV.
