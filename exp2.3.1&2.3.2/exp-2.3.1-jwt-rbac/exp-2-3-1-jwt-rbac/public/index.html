How this works

  1. You logged in → server verified username/password.
  2. Server created a JWT containing your username and role.
  3. Every protected API call sends Authorization: Bearer <token>.
  4. The authentication filter validates the signature and expiry.
  5. Role-based rules decide if you may enter Admin / Editor / Viewer pages.
