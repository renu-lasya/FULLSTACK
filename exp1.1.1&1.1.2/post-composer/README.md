# Experiment 1.1.1 – Post Composer

## Aim

To develop a simple Post Composer interface using React.js for creating and managing social media posts.

## Objectives

- To create a post composer using React.js.
- To manage post content using React state.
- To create a simple and user-friendly interface.
- To understand basic React components and event handling.


## Requirements

- Node.js
- npm
- React.js
- Visual Studio Code
- Web Browser

## Description

The Post Composer is a React.js application that allows users to enter and create post content through a simple interface.

React state is used to store and manage the post content. The application demonstrates basic concepts such as components, state management, input handling, and event handling.

## Procedure

1. Create a React.js project.
2. Create the Post Composer component.
3. Add an input or text area for entering post content.
4. Use React state to store the entered content.
5. Add a button to create the post.
6. Display the created post on the screen.
7. Add suitable CSS for the user interface.
8. Run and test the application.

## Expected Outcome

A simple Post Composer application is successfully created using React.js.

The user can enter post content and create a post through the interface.
