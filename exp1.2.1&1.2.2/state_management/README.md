# Experiment 1.2.1 – Centralized State Management

## Aim
To implement centralized state management using Redux Toolkit for managing posts and platform data.

## Objectives
- To understand global state management.
- To implement Redux Toolkit.
- To manage application data using a centralized store.
- To reduce prop drilling between components.

## Technologies Used
- React.js
- Redux Toolkit
- React-Redux
- JavaScript
- Node.js
- VS Code

## Description
This experiment demonstrates how Redux Toolkit can be used to manage application state in a centralized way.

A Redux store acts as a single source of truth for application data. Redux slices are used to manage different types of data such as posts and platforms.

## Implementation
- Created a Redux store.
- Created slices for managing posts.
- Defined the initial state.
- Implemented actions and reducers.
- Connected React components with Redux.
- Used Redux hooks to access and update the state.

## Expected Outcome
- Centralized state management is implemented.
- Posts and platform data are managed efficiently.
- Prop drilling is reduced.
- The application becomes easier to maintain and scale.
